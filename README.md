# Tyler's Game — SpinKeep

Planning + interactive mockup for a viral **iOS/Android social slots** game (Clash-style retention, not real-money gambling).

## Mockup

See [`mockup/`](./mockup/) — run with:

```bash
cd mockup && npm install && npm run dev
```

## Vision (short)

- Free-to-play tokens with a **daily streak claim** that pulls players back
- **Multiple slot games**, one shared wallet
- **Clans/teams**, friends, and **gifts**
- Later: buy token packs (IAP)
- Virtual tokens only — no cash-out in v1
