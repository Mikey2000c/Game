# SpinKeep — Social Slots Mockup

Interactive mobile UI mockup for a viral social casino:

- **Daily Keep Bonus** with 7-day streak
- **Multi-game lobby** (Neon Orchard, Vault Rush, Raid Spins)
- **Clans** with goals / chest energy (Clash-inspired)
- **Friends & gifts**
- Playable **demo spin** cabinet
- Token wallet + IAP placeholder

## Run

```bash
cd mockup
npm install
npm run dev
```

Open the local URL. On a phone-sized viewport it goes full-bleed; on desktop it sits in a device frame.

## Product notes (planning)

This is a **social casino** (virtual tokens, no cash-out). Retention hooks:

1. Daily streak that grows rewards and resets if you miss
2. Clan pressure (donations, weekend raids, shared chests)
3. Gifts that ping friends back online
4. Multiple short-session games off one wallet
5. Later: token packs via App Store / Play IAP
